# データベース閲覧記録 (local_dbviewrecorder)

[English README](README_en.md)

## 概要

Moodleのデータベースモジュールでは、個別エントリの閲覧や検索が標準ログ上で区別しづらい場合があります。このプラグインは、データベースモジュール上での「個別エントリ閲覧」と「検索実行」を独立したMoodleイベントとして記録します。

## 主な機能

- 個別エントリ閲覧を `Record viewed` イベントとして記録
- 検索実行を `Record searched` イベントとして記録
- 該当データベース活動の course module context でログを記録
- `cmid`, `dataid`, `courseid` をイベントの `other` データに保持
- 検索ログでは検索語を `other.searchquery` に保持
- 独自ログテーブルを持たず、Moodle標準ログストアを利用

## インストール

1. このリポジトリを Moodle の `local/dbviewrecorder` に配置します。
2. Moodleの管理画面からプラグイン更新を実行します。
3. サイトのキャッシュを必要に応じて削除します。

## 動作概要

`mod_data` のページで JavaScript を読み込み、URLパラメータから `rid`, `id`, `d`, `search`, `f_*` を取得します。該当する操作が検出されると `local/dbviewrecorder/logrecord.php` に送信し、サーバ側でデータベース活動のコンテキストを解決してMoodleイベントを発火します。

## 個人データについて

このプラグイン自体は独自テーブルに個人データを保存しません。発火したイベントは、サイトで有効化されているMoodle標準ログストアに保存される場合があります。ログの保持期間や削除は、各ログストアの設定に従います。

## 必要環境

- Moodle 4.4 以降

## 注意事項

このプラグインはMoodle標準ログストアに依存します。ログを残すには、サイト側で適切なログストアが有効になっている必要があります。
